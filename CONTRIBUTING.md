# Участие в разработке

Проект находится на стадии технического пилота. Крупные изменения сначала обсудите
в GitHub issue: формат файлов и интерфейс операций ещё формируются.

## Локальная работа

1. Сделайте fork, клонируйте его и создайте отдельную ветку.
2. Установите Node.js 24.2+ и выполните `npm ci`.
3. Запустите `npm run dev -- --port 5178`.
4. Перед PR выполните `npm test`, `npm run typecheck`, `npm run build` и
   `npm run test:browser`. Для установки браузера: `npx playwright install chromium`.

В PR объясните пользовательскую проблему, изменение поведения и выполненные проверки.
Для исправления ошибки добавьте воспроизводящий её тест. Для изменений интерфейса
приложите скриншот. Не добавляйте пользовательские проекты, ключи, `.env`, кэш,
`node_modules` или сборку. Синтетические примеры храните в `examples/`.

## Архитектура

Модель Screen независима от редактора. Puck-specific код находится в `src/puck/`.
Не сохраняйте внутренний AppState Puck вместо канонического документа.
Ограничения и последовательность работы описаны в `ROADMAP.md` и `docs/design.md`.

## Лицензирование

Отправляя изменения, вы соглашаетесь предоставить их под MIT и подтверждаете,
что вправе это сделать. Для стороннего кода сохраняйте оригинальные notices.
Добавляя зависимости, обновите `THIRD_PARTY_NOTICES.md` и проверьте их условия.

Общайтесь уважительно, обсуждайте идеи и поведение кода, а не личности участников.
