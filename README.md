# Local Design Studio

Open source студия интерфейсов с локальными файлами. Статус: ранний технический пилот.

[MIT](LICENSE) · [Roadmap](ROADMAP.md) · [Участие](CONTRIBUTING.md)

Технический пилот визуального редактора интерфейсов. Собственный формат экранов
преобразуется в Puck и обратно; компоненты рисуются настоящим React.

## Запуск

Требуется Node.js 24.2+ и npm. Проверенные версии зависимостей закреплены в lockfile.

```bash
npm ci
npm run dev -- --port 5178
```

Открыть http://127.0.0.1:5178. Сервер слушает только локальный интерфейс.
Загрузка пакетов требует интернета; открытый пилот использует локальные ресурсы.

## Как попробовать

1. Выделить текст «Расходы на ремонт» на холсте и изменить поле «Текст» справа.
2. Проверить ID выделенного узла в верхней панели.
3. Переключить ширину превью между телефоном (390 px) и компьютером (1280 px).
4. Нажать «Внешняя правка»: вложенный показатель станет «180 000 ₽».
5. Открыть «Структура» и посмотреть собственный JSON-документ.
6. Нажать «Экспорт JSON», сохранить файл, открыть его через «Открыть JSON».

Локальные браузерные загрузки содержат самостоятельный документ. В репозитории
есть начальный экран `examples/budget.json`. Импорт до 1 МБ; неверный файл не
заменяет текущий экран. Неверное значение в редакторе отклоняется с восстановлением
последнего корректного документа.

**Изменения до экспорта живут в памяти вкладки. Автосохранения пока нет.**
Кнопка «Просмотр» показывает пояснение пилота и не публикует проект. Демонстрационная
кнопка внутри экрана не отправляет данные в API продукта.

## Проверки

```bash
npm test
npm run typecheck
npm run build
npm run test:browser
```

При отсутствии браузера: `npx playwright install chromium`.
Playwright сам поднимает сервер на 5178. На этом порту не должен работать другой проект.
Скриншоты создаются в `test-results/`, отчёт проверок — в `docs/pilot-results.md`.

## Что входит в пилот

- Вложенные Stack/Card, Text, Button и Metric с редактируемыми свойствами.
- Отдельный канонический JSON, стабильные ID и ревизия документа.
- Получение выделенного узла через public API Puck.
- Импорт/экспорт, ручное редактирование и демонстрация внешнего изменения.

## Ограничения и следующий этап

Внешнее изменение переоткрывает Puck: сбрасываются его выделение и внутренняя
история отмены. Единой истории ручных и агентских правок ещё нет. Неизвестные
компоненты отклоняются. Формат пилота не содержит токены, ассеты и фикстуры полной
студии; его версия 1 не считается окончательной версией MVP.

MCP, файловый сервис, облачный чат, GitHub-синхронизация и адаптер product-repository
ещё не реализованы. Следующий этап — файловый сервис и общий движок изменений;
затем MCP и Git. Качество агента пилот не проверяет: «Внешняя правка» — локальная
демонстрация пути обновления редактора.

Архитектура — [docs/design.md](docs/design.md), план — [docs/pilot-plan.md](docs/pilot-plan.md).

## Оформление пилота

| До                                  | После                                                           |
| ----------------------------------- | --------------------------------------------------------------- |
| Базовые блоки без общего оформления | Системная типографика, фон и карточки с мягкой тенью            |
| Обычные числа и браузерная кнопка   | Табличные цифры, крупный показатель и кнопка высотой 44 px      |
| Технические имена полей             | Русские названия компонентов и подписей                         |
| Нет оболочки проекта                | Панели открытия/экспорта, статуса, выделения и структуры        |
| Нет состояний отказа                | Видимая ошибка импорта/ввода и сохранение корректного документа |
