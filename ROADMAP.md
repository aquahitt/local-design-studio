# Roadmap

## A. Технический пилот — выполнено

- [x] Собственный формат экранов и стабильные ID.
- [x] Вложенные компоненты и визуальное редактирование.
- [x] Импорт/экспорт JSON и демонстрация внешней правки.
- [x] Проверки мобильного и desktop-превью.

## B. Надёжные локальные документы

- [ ] Файловый сервис с атомарным сохранением и восстановлением.
- [ ] Единый движок операций, ревизии и общая история undo/redo.
- [ ] Обработка повторных запросов и конфликтов ручных/внешних правок.
- [ ] Версии схемы, лимиты документов и сохранение неизвестных компонентов.

## C. Управление AI-агентами

- [ ] Локальный MCP: документы, выделение и предложения правок.
- [ ] Варианты, комментарии и решения в файлах.
- [ ] Проверка с реальным MCP-клиентом.

## D. Версии и подключение продуктов

- [ ] Git status, commit, push и безопасное получение обновлений.
- [ ] Восстановление версии без перезаписи текущей работы.
- [ ] Подключаемые библиотеки компонентов и фикстуры.

Даты выпуска не установлены. MCP и автосохранение не входят в текущий пилот.
