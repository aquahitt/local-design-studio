# Roadmap

## A. Технический пилот — выполнено

- [x] Собственный формат экранов и стабильные ID.
- [x] Вложенные компоненты и визуальное редактирование.
- [x] Импорт/экспорт JSON и демонстрация внешней правки.
- [x] Проверки мобильного и desktop-превью.

## B. Надёжные локальные документы

- [x] Файловый сервис с атомарным сохранением и восстановлением.
- [x] Единый движок операций, ревизии и общая история undo/redo.
- [x] Обработка повторных запросов и конфликтов ручных/внешних правок.
- [x] Версии схемы, лимиты документов и сохранение неизвестных компонентов.

## C. Управление AI-агентами

- [x] Локальный MCP: документы, выделение и предложения правок.
- [ ] Варианты, комментарии и решения в файлах.
- [x] Проверка с реальным MCP-клиентом.

## D. Версии и подключение продуктов

- [ ] Git status, commit, push и безопасное получение обновлений.
- [ ] Восстановление версии без перезаписи текущей работы.
- [x] Подключаемые библиотеки компонентов и фикстуры.

Даты следующих выпусков не установлены. Локальные документы, MCP и SDK доступны в основной студии; старый Puck-пилот сохранён отдельно по `/pilot`. Свободный холст, компонентные instances/variants и импорт из других редакторов остаются открытыми задачами.
