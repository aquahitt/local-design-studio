# Сообщения о безопасности

Для уязвимости, которая затрагивает пользовательские проекты, выполнение доверенного React-кода, локальный bearer token или доступ к файловой системе, используйте [private vulnerability report](https://github.com/aquahitt/local-design-studio/security/advisories/new). Не помещайте секреты, реальные проекты или `.studio/connection.json` в публичный issue. Если приватный report недоступен, откройте issue с просьбой о приватном канале без подробностей эксплуатации.

Укажите версию/commit, ОС, воспроизводящий синтетический проект, ожидаемый и фактический результат. Проект находится в alpha; SLA ответа и поддержка всех старых binaries не обещаны. Исправления выпускаются для текущей линии alpha, а границы формата опубликованы в [compatibility policy](docs/compatibility.md).

React-библиотека является доверенным исполняемым кодом. Импортируйте её только из источника, которому доверяете. Канонический JSON содержит декларативные данные; проверка JSON не превращает произвольную библиотеку в безопасный sandbox. MCP требует существующего локального владельца или явного `--project`, а применение предложений по умолчанию требует UI approval. Не передавайте credentials третьим лицам.
