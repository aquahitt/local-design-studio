Не опубликовано: версия и tag выбираются после прохождения release CI на одном commit. В release pipeline добавлены переносимые scene/frame/text/vector/image данные, определения/instances компонентов, annotations и React handoff, встроенный MCP helper и подключение доверенных библиотек. Точные ограничения описаны в документации соответствующих функций.

Исправлены два расхождения готового desktop с development: нативный компилятор библиотеки читает публичные SDK-исходники из `app.asar.unpacked`, а PNG-снимки на Retina сохраняют размеры в CSS pixels. Автоматизированная [desktop-приёмка](desktop.md#автоматическая-desktop-приёмка) проверяет встроенный MCP helper, операторское доверие библиотеке, UI review и перезапуск владельца на публичных synthetic данных. Локальное прохождение macOS arm64 не заменяет матрицу остальных ОС или ручную установку скачанного artifact.

Перед обновлением прочитайте [совместимость и резервные копии](compatibility.md). Schema-1 migration сохраняет точные исходные байты до rewrite; для schema-2 проекта требуется собственная полная копия папки. Новые scene/annotations поля могут не открыться в старом alpha binary.

Установщики остаются unsigned alpha. Для каждого platform artifact pipeline добавляет лицензии, standalone helper, build metadata и SHA256SUMS; tag build добавляет provenance bundle. [Проверка и воспроизводимая сборка](release.md). Не заявляйте выпуск RC, пока matrix/core/browser/MCP/filesystem/Git gates и ручная установка скачанного artifact не подтверждены.

# Предыдущий alpha.2: инструкция установки

Desktop alpha 2: исправлена целостность macOS-подписи, добавлена проверка codesign и запуск из готового DMG.

Desktop alpha Local Design Studio: встроенные Chromium и Node.js, создание/открытие проектов, сохраняемый пример, недавние проекты, настоящий редактор и изолированные превью. Установка Node/npm/Git и запуск сервера для работы не требуются.

Скачай файл для своей системы:

- macOS Apple Silicon: arm64 DMG или ZIP; Intel: x64 DMG или ZIP. Перенеси LocalDesignStudio.app в Applications.
- Windows x64: Setup.exe (установщик) или ZIP (распакуй всю папку и запусти LocalDesignStudio.exe).
- Linux x64: DEB для Ubuntu/Debian или ZIP. ZIP требует системные библиотеки Electron; DEB устанавливает заявленные зависимости через пакетный менеджер.

Это **alpha без Developer ID/notarization и Authenticode**. macOS-приложение имеет техническую ad-hoc подпись для целостности; она не подтверждает разработчика перед Apple. macOS/Windows могут показать предупреждение о неизвестном разработчике или заблокировать запуск. Такой релиз предназначен для раннего тестирования; подписанные установщики и обновления будут отдельным этапом.

Выбери «Создать проект» и пустую папку либо «Открыть проект» и папку с project.json. Проекты хранятся отдельно от приложения. Обновление приложения не удаляет файлы. Перед работой с ценными данными сделай копию папки проекта. Приложение содержит только публичные example/builtin библиотеки. В этой предыдущей alpha.2 внешние React-библиотеки подключаются через исходную версию студии; desktop MCP helper и встроенные обновления не включены.

Пакеты проверены автоматическим запуском упакованного приложения на соответствующих runner macOS/Windows/Linux: создание проекта, iframe, редактирование, сохранение на диск и повторное открытие после перезапуска. SHA256SUMS сопровождают пакеты. В релиз не включены пользовательские проекты, приватные библиотеки или локальные настройки.

Если macOS блокирует alpha: сначала перенеси приложение из DMG в /Applications и попробуй «Настройки системы → Конфиденциальность и безопасность → Всё равно открыть». Полностью автоматический запуск без ручного разрешения требует Developer ID и notarization.

Если для alpha.2 из этого релиза macOS всё ещё пишет «damaged», проверь установленную копию и сними карантин только с этого приложения. Команда после `&&` выполнится лишь при успешной проверке подписи:

```bash
codesign --verify --deep --strict "/Applications/LocalDesignStudio.app" && xattr -dr com.apple.quarantine "/Applications/LocalDesignStudio.app"
```

Затем открой приложение снова. Это ручное разрешение для выбранной alpha; оно не отключает Gatekeeper для остальных приложений.
