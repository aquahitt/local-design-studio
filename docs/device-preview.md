# Размеры и модель устройства

На странице «Экраны» выбери тип устройства или введи ширину/высоту и нажми «Применить размеры». Размеры указаны в CSS px, а не в физических пикселях дисплея. Пресеты — типовые профили телефонов, планшетов и компьютеров; они не заявляют точное соответствие конкретной модели или версии ОС.

«Повернуть устройство» меняет ориентацию. В раскрывающемся блоке можно задать зоны сверху, справа, снизу и слева и форму выреза камеры. Полный размер устройства сохранён в документе; iframe получает рабочий размер за вычетом этих зон. Например, окно 390 × 844 с зонами 54 сверху и 34 снизу показывает приложение в 390 × 756. Поэтому `vh`, медиазапросы и фиксированные панели работают внутри доступной области.

Переключатель «Шторка уведомлений» показывает визуальную системную панель поверх приложения и блокирует взаимодействие с перекрытой областью. Это режим просмотра; он не изменяет документ, не создаёт шаг отмены и не сохраняет вымышленные уведомления. Нативные уведомления, браузерный chrome, DPR, датчики и CSS `env(safe-area-inset-*)` не эмулируются. Системные зоны уже исключены из области iframe.

Выбор устройства, размеры и зоны сохраняются одним пакетом с общей отменой/повтором. Несохранённый ввод блокирует переход в другой раздел. Внешняя правка не стирает черновик: перед сохранением поверх новой ревизии нужно выбрать соответствующее действие. При удалении экрана черновик остаётся до явного сброса и не применяется к другому экрану.

## Документ и агенты

Схема v2 читает прежние документы с `viewport: {"width":390}`. Документы с `height`/`device` требуют версии студии с поддержкой этих полей; более старые строгие валидаторы отклонят их. Высота и профиль устройства необязательны. Когда они заданы, документ хранит:

```json
{
  "width": 390,
  "height": 844,
  "device": {
    "preset": "phone-pill",
    "orientation": "portrait",
    "cutout": "pill",
    "safeArea": {"top":54,"right":0,"bottom":34,"left":0}
  }
}
```

`setViewport` принимает обязательные `pageId` и `width`, необязательные `height` и `device`. `device:null` удаляет профиль. Операция только с шириной сохраняет заданную высоту и зоны, а при изменении размеров помечает прежний профиль как `custom`. Агент получает расширенную JSON Schema и в UI-контексте видит полный размер и `viewport.content` — рабочую ширину/высоту.

Ширина: 320–3840, высота: 240–3840, каждая зона: 0–240. Все значения целочисленные; рабочая область не меньше 120 × 120. Неверные параметры отклоняются атомарно. Предварительный просмотр предложений использует ту же модель устройства.

Настройки устройства по умолчанию скрыты. Кнопка рядом с добавлением экрана и масштабом показывает текущий профиль и размеры; повторное нажатие закрывает блок без потери черновика. Несохранённый ввод отмечается на кнопке.

В блоке устройства доступны «Применить ко всем» и «Применить к группе». Кастомный селект показывает группы и число экранов; пустую группу применить нельзя. Переносятся текущие значения полей (включая черновик), полный профиль, вырез и системные зоны. Для старого экрана без высоты используется текущая высота превью 850 px. Шторка уведомлений остаётся состоянием просмотра.

Все целевые экраны изменяются одной атомарной пачкой setViewport с проверкой ревизии; undo отменяет действие целиком. Если выбранная группа не содержит исходный экран, его документ не меняется и несохранённый ввод сохраняется; перед дальнейшим сохранением нужно принять актуальную ревизию или сбросить черновик.
