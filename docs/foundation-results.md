# Проверка файловой студии и дизайн-систем

Проверено 2026-10-04 в Node 24.2 / Chromium. Связанные задачи: #2, #3, #4, #5, #6, #15, #17, #18, #30. Это компонентная студия; свободный холст и остальные roadmap-задачи не включены в данный этап.

| ------ | ---------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------- |

| #3     | транзакции, requestId, ревизии, общая история                                            | атомарный отказ, конфликт, повтор/иной payload, restart и undo/redo                                                  |

Результаты: 75 unit/service/library тестов проходят при включённой реальной библиотеке; 12 основных браузерных сценариев; отдельные сценарии публичной внешней библиотеки и локального продукта. TypeScript и обе сборки (чистая и с локальной библиотекой) проходят. Скриншоты тестов остаются локально в `test-results/`, а сборки — в игнорируемой `dist/`.

Реальный адаптер исследовал 148 экспортов: 72 компонента, 69 renderer с синтетическими fixtures и 3 компонента с обязательным контекстом приложения. Доступны 139 токенов и четыре PWA/web light/dark режима. Изображение из fixture материализуется в `assets/<sha256>.svg` и загружается после перезапуска страницы. Модальные окна/порталы ограничены своим iframe. Проверено восстановление renderer после некорректного JSON shape и последующей корректной правки.

Известные границы: доверенные библиотеки, ограниченное пассивное SVG-подмножество, polling, неограниченная пока история; библиотечные миграции вызываются явно через SDK. Git-панель, instances/variants свободного холста, импорт Figma/Penpot/Zeplin и sandbox для недоверенных extensions остаются отдельными задачами. Подробности: [project-format](project-format.md), [SDK](../examples/library/README.md).
