# Группы проекта

Группы объединяют экраны, компоненты библиотеки и токены, например PWA Buyer, PWA Business и Site. Один элемент может входить в несколько групп. Категории библиотеки сохраняются отдельно.

Группы хранятся в необязательном поле `groups` документа проекта: `{id, name, pages, components, tokens}`. Связи используют стабильные screenId, типы компонентов и имена токенов. Переименование группы не меняет связи. Удаление группы не удаляет элементы; удаление экрана/токена очищает его связи. Недоступные компоненты остаются в составе группы для восстановления библиотеки.

В интерфейсе доступны фильтры «Все», «Без группы» и созданные группы. Окно управления позволяет создать, переименовать и удалить группу, выбрать её состав и сохранить изменения одной операцией. Черновик фиксирует ревизию; при внешнем изменении сохранение отклоняется, чтобы не затереть новую версию. Закрытие окна явно отменяет черновик.

Агенты читают группы в проекте и меняют их операцией `setGroups` с baseRevision. Undo/redo, предложения и экспорт проекта используют общую модель. Старые документы без групп читаются без миграции; старые строгие версии студии не принимают новое поле.

Проверка: валидация ссылок/дубликатов, атомарность изменения, очистка связей, создание группы через UI, фильтрация экранов/компонентов, undo/redo и повторное открытие.
