# Заливка фрейма изображением

Выделите фрейм на странице экранов. В инспекторе «Заливки» можно импортировать
изображение и добавить его заливкой либо выбрать уже существующий ресурс проекта.
PNG, JPEG и WebP нормализуются в PNG, SVG проходит проверку пассивного содержимого.
Файлы сохраняются в `assets/`; облачный сервис и CDN не нужны.

У заливки есть четыре способа размещения:

| Режим             | Поведение                                                    |
| ----------------- | ------------------------------------------------------------ |
| Заполнить фрейм   | Сохраняет пропорции, заполняет всё окно и обрезает края.     |
| Вписать целиком   | Показывает изображение целиком; свободное место прозрачно.   |
| Кадрировать       | Сохраняет заданное положение, масштаб и поворот внутри окна. |
| Повторять плиткой | Повторяет изображение с заданной матрицей плитки.            |

В первых двух режимах положение X/Y задаётся долями от 0 до 1: 0 — начало,
0,5 — центр, 1 — конец. При переходе к кадрированию текущее расположение
сохраняется по фактическим размерам декодированного изображения, включая SVG без
заданных пиксельных размеров. Пока изображение не загружено, кадрирование недоступно.

В окне кадрирования перетаскивайте изображение, используйте ручки масштаба и
поворота. Масштаб сохраняет пропорции; Alt/Option меняет его относительно центра,
Shift при повороте включает шаг 15°. Кнопки под холстом доступны с клавиатуры.
Стрелки перемещают изображение на 1 px, Shift со стрелками — на 10 px. Escape
отменяет текущий жест; следующий Escape закрывает окно. Для точного ввода есть
дополнительные поля матрицы UV → px в инспекторе.

Все эти действия меняют черновик слоя. «Готово» закрывает кадрирование;
«Применить слой» сохраняет весь черновик одним пакетом с одной отменой Undo.
Незавершённое число вроде `-` или `1e` сохраняется при потере фокуса и блокирует
применение до исправления. При внешнем изменении проекта черновик не перезаписывает
новую ревизию автоматически. Поздний результат импорта не заменяет уже изменённую
заливку. Успешно импортированный, но не применённый ресурс остаётся в библиотеке
как неиспользуемый: удалить его можно отдельно.

Resize меняет окно фрейма: заполнение/вписывание адаптируются, а кадрирование и
плитка сохраняют свою локальную матрицу. Scale масштабирует весь слой вместе
с изображением, оформлением и содержимым. Порядок заливок, opacity и blend mode
действуют так же, как для градиентов. Обводка и внутренние тени остаются над фоном.

В Pages demo импорт файлов проекта недоступен; он работает в локальной студии и
desktop-приложении. Изображения не добавляют маски или несколько обводок — это
следующие части поддержки оформления.
