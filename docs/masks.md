# Явные группы масок

Группа `scene.kind: "mask"` хранит геометрию контейнера, необязательную прозрачность,
`maskMode: "alpha" | "luminance"` и единственный ordered slot `children`.
Ровно один прямой ребёнок имеет `maskSource: true`. Роль источника относится к его
членству в группе: это не ссылка на индекс и не отдельная заливка. Собственные
заливки/обводки/тени/clip у контейнера маски запрещены. Старые документы при чтении
не переписываются; сборка без поддержки mask может отклонить новый документ.

Источник задаёт прозрачность остальных детей независимо от своего положения в
списке. Alpha учитывает прозрачность; luminance дополнительно учитывает яркость.
Порядок детей и их IDs сохраняются при смене источника. Исходный слой доступен для
редактирования через дерево или кнопку «Редактировать источник», но не участвует
в обычном выборе содержимого маски на холсте. Вне редактирования его DOM скрыт,
`inert` и исключён из accessibility tree; техническое SVG не дублирует node IDs.

## Редактирование и операции

Блок «Маска» в действиях над слоями создаёт группу из соседних слоёв одного
контейнера, с явным выбором источника и режима. Разорванное выделение не
перегруппировывается с изменением внешнего порядка отрисовки. Геометрия переводится
в локальные координаты группы с сохранением мировых affine transforms.

- `setMaskSource {nodeId, sourceNodeId}` меняет единственного прямого ребёнка с ролью
  источника, не переставляя слои.
- `removeMask {nodeId}` превращает контейнер в frame, удаляет maskMode и прямые
  маркеры источника. Геометрия, opacity, ID и порядок сохраняются.
- `unwrapMask {nodeId}` поднимает детей в родителя с сохранением мировых transforms.
  При групповой opacity != 1 операция отклоняется: отдельным детям нельзя
  безопасно передать групповое смешивание. Используйте removeMask.

Операции проходят общую проверку lock предков и потомков, baseRevision,
ProjectStore, atomic save и Undo/Redo. Удаление или перенос источника из группы
требует явной замены источника либо снятия маски в том же валидном batch. Parser не
назначает замену автоматически. Отдельное копирование источника снимает только его
корневую роль; копирование целой маски сохраняет вложенные роли.

UI сохраняет черновик при внешней ревизии и требует явного обновления основы перед
применением. Блокировки отключают изменение маски. Кнопки удаления источника и
Delete/Backspace защищены; исходная модель дополнительно проверяет итоговый batch.

## Отрисовка, экспорт и ограничения

`compileMaskSource` и `serializeMaskSVG` создают конечный self-contained SVG с общими
правилами геометрии, заливок, обводок и теней. CSS mask накладывается на обычное
HTML-поддерево содержимого, сохраняя его интерактивность. Preview и автономный React
handoff используют один descriptor и барьер готовности. SVG декодируется до
публикации готовой ревизии; устаревший decode не подменяет новую маску.

Поддержаны источники из фреймов и векторов с solid/linear/radial paint, скруглением,
обводками, тенями, affine transforms и clip. Декларативные instances
материализуются. Источники из текста, изображений, библиотечных компонентов и
вложенных масок пока не поддержаны; документ сохраняет их структуру, но renderer
показывает диагностику. Содержимое маски может оставаться обычным DOM, включая
библиотечные компоненты. Порталы вне этого DOM-поддерева не маскируются.

Неизвестный источник или ошибка подготовки дают прозрачную маску и явное
предупреждение. Снятия маски через `mask-image: none` при ошибке нет. PNG в service и
Electron проверяет готовность в своей области снимка и возвращает типизированную
ошибку `MASK_SOURCE_UNSUPPORTED`, `MASK_SOURCE_LIMIT`, `MASK_IMAGE_UNAVAILABLE` или
`MASK_RENDER_UNAVAILABLE`. Изолированный экспорт обычного дочернего слоя или
самого источника не зависит от маски предка. Экспорт группы сохраняет прозрачные
отверстия. Handoff сообщает ограничения через diagnostics, а его runtime включает
их в результат `waitForResources`; прежний image-only барьер остаётся доступен.

Конечная область маски — консервативная affine AABB оформления с округлением наружу;
для blur используется envelope 6σ + 2px, поэтому это не точная граница непрозрачных
пикселей. Пределы источника: 8192px по стороне, 16 777 216 CSS pixels, 10 000 узлов,
глубина 64; сериализованное SVG не более 8MB. Пустой источник даёт прозрачную
поверхность 1×1. PNG отдельно сохраняет ограничения capture/raster из
[render.md](render.md). Hit testing маски пока ограничен геометрическими границами,
без чтения alpha каждого пикселя.

MCP `capabilities_read` публикует `masks` с режимами, операциями, источниками,
границами и ограничениями. Полная совместимость импорта Figma и текстовые/растровые
источники этим изменением не заявлены; #10 остаётся частично выполненной задачей.

Проверки: `mask-validation`, `mask-operations`, `mask-groups`, `mask-picking`,
`mask-source`, `mask-handoff`, service `mask-contract`, `mask-capture`, `mask-render`;
браузерные `masks`, `mask-preview`, `mask-warning`, `mask-actions`,
`accessibility/masks`, standalone handoff fixture и packaged desktop MCP scenario.
