# Доска компонентов

Цель: заменить страницы каталога адаптивной masonry-доской с накопительной подгрузкой по 12 компонентов.

1. Catalog.tsx: независимая карточка измеряет высоту через ResizeObserver; CSS Grid размещает карточки без обрезки. IntersectionObserver у нижнего края добавляет следующую порцию; доступная кнопка остаётся резервным способом. Поиск и категория сбрасывают выдачу. Конец списка и отсутствие результатов явные.
2. Preview.tsx и iframeentry.tsx: опциональная автоматическая высота превью через проверенный postMessage; только компонентные превью, диапазон 120–600 px. Другие экраны сохраняют фиксированную высоту.
3. styles.css: крупные превью, компактные подписи и действия, фильтры категории; адаптивность и видимый keyboard focus.
4. Проверить браузером прокрутку более 12 компонентов, отсутствие дублей, поиск/категорию, пустую выдачу, смену fixture и добавление на экран; выполнить typecheck/build и существующие тесты.
