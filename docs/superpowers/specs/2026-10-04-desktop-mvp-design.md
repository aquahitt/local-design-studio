# Desktop MVP — утверждённый дизайн

Electron-приложение поставляется со встроенными Chromium и Node.js, работает без npm/Vite сервера пользователя. React UI и превью загружаются из пакета через привилегированную локальную схему studio://app. Node utility process запускает существующий владелец project.json с loopback API и общими ревизиями/историей. Главный процесс управляет выбором папок, недавними проектами, жизненным циклом worker и ограниченным preload мостом. Рендереры sandboxed, nodeIntegration выключен, iframe не получает desktop API. Навигация и сетевые переходы ограничены.

Стартовый экран: создать проект (имя + пустая выбранная папка), открыть существующий проект, открыть сохраняемый пример, последние проекты. Данные сохраняются в пользовательской папке; настройки/пример в userData. Отказ или повреждённый проект показывают ошибку без перезаписи. Закрытие/смена проекта ожидает остановки сервиса и освобождения блокировки. Существующий владелец с совместимыми метаданными может быть подключён, несоответствие диагностируется.

MVP содержит публичные example/builtin библиотеки. Внешние React библиотеки и MCP helper — следующий отдельный этап; текущий MCP может подключаться к desktop владельцу с установленным runtime, desktop не требует этого для ручной работы. Нет облачных проектов или автоматического Git push.

Release pipeline: macOS arm64/x64 DMG+ZIP, Windows x64 installer+ZIP, Linux x64 DEB+ZIP; Linux portable ZIP может требовать системные библиотеки Electron. Автотесты packaged Electron проверяют создание/открытие, реальный iframe, сохранение/перезапуск, ошибки и ограниченный bridge. Подписанные публичные релизы требуют секретов владельца; unsigned prerelease явно обозначен. Обновления и сторонние библиотеки не включены в MVP.
