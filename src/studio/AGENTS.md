# Редактор и превью

Читай ../../.codex/PROJECT.md, текущие client/Preview и документацию нужного экрана.
Используй StudioIconButton, StudioSelect, i18n и семантические studioPalette токены.

- UI работает через клиент сервиса и общие операции; optimistic state не означает
  сохранение на диск. Конфликтующий draft сохраняется до явного решения пользователя.
- Предложение preview симулируется на копии проекта; сравнение и подтверждение относятся
  к точному batch и revision, без изменения оригинала при просмотре.
- Каталог показывает реальные компоненты и fixtures. Проверяй раскрытые состояния,
  portals/modals, достаточную ширину и динамическую высоту карточек с infinite loading.
- Select со страницами сохраняет ID и групповую структуру; rename не меняет ключи выбора.
  Icon buttons имеют доступное имя, custom select — keyboard/focus/ARIA.
- Sidebar, camera zoom и UI theme preferences не переписывают document geometry/theme
  без соответствующего пользовательского действия. Превью учитывает выбранные темы.
- Device frame и notification shade — симуляция, а не эмулятор системного UI устройства.
- Новый текст проходит i18n, обе темы и целевой browser-сценарий. Не внедряй code внешнего
  продукта в Pages demo; оно использует studio-ui библиотеку.
